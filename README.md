# -Sales_Data_Analysis_using-SQL-Python
This project demonstrates the execution of basic, intermediate, and advanced SQL queries using Python, directly interfacing with a SQL database. The goal is to extract insights from a customer-orders dataset using real-world business questions.

Project Overview
Using Python and SQL, this project focuses on analyzing customer, sales, and order data through a variety of queries. The queries are categorized into three levels:

Basic Queries – Simple aggregations and counts

Intermediate Queries – Grouping, joins, averages, correlations

Advanced Queries – Time-series analysis, retention, moving averages, growth metrics

All queries are executed using Python scripts via an SQL database connection (e.g., SQLite, PostgreSQL, or MySQL) in Visual Studio Code.

1. Basic Queries
List all unique cities where customers are located

Count the number of orders placed in 2017

Find the total sales per category

Calculate the percentage of orders that were paid in installments

Count the number of customers from each state

2. Intermediate Queries
Calculate the number of orders per month in 2018

Find the average number of products per order, grouped by customer city

Calculate the percentage of total revenue contributed by each product category

Identify the correlation between product price and the number of times a product has been purchased

Calculate the total revenue generated by each seller, and rank them by revenue

3.  Advanced Queries
Calculate the moving average of order values for each customer over their order history

Calculate the cumulative sales per month for each year

Calculate the year-over-year growth rate of total sales

Calculate the retention rate of customers (purchase within 6 months of first order)

Identify the top 3 customers who spent the most money in each year

🛠️ Technologies Used
Python (pandas, matplotlib/seaborn)

SQL (aggregations, joins, window functions)

Visual Studio Code (development environment)

Jupyter Notebook (optional) for exploratory analysis
